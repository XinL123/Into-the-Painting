# Into the Painting · 入画

[https://xinl123.github.io/Into-the-Painting/](https://xinl123.github.io/Into-the-Painting/) 👈 Try it

An English-language interactive experience about the small stories hidden inside traditional Chinese paintings. Pick a scroll from a brushed gallery to unroll an 18,000-px stretch of Zhang Zeduan's *Along the River During the Qingming Festival*, then choose a red mark. The scroll recedes and that one moment comes forward at full resolution with a short "Did you know?" story. 13 stories so far, each with a real field recording (Freesound, CC0), built with a canvas renderer, Web Audio, GSAP, and Vite.
