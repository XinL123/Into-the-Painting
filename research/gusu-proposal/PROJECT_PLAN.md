## 建议结果

第二幅作品为徐扬《姑苏繁华图》（Prosperous Suzhou），1759年，辽宁省博物馆藏。以上基本信息见上海博物馆官方目录： https://www.shanghaimuseum.net/mu/frontend/pg/m/article/id/CI00005093 。尺寸资料彼此不一，界面暂不显示实物尺寸；不要混用不同来源数字。

入口采用清明左侧相邻画框位置。当前那里实际是巨然《溪山兰若图》，不是姑苏图；未来替换图像、作品名、作者与可进入状态，保留画框位置、比例、倾角和现有进出动画。已有清明入口继续工作。

13个建议热点见 STORY_RESEARCH.md、hotspots.json 和图片。每一个坐标都来自 master-research.jpg；另外的局部扫描只帮助辨认。两项替换明确提出供审阅：考试糕点 → 阊门人群；虎丘盆景 → 虎丘塔。没有为这些未确认细节填写猜测坐标。

故事顺序建议按母图从右向左：村塾 → 家庭纺织 → 山游 → 花船 → 园林 → 九孔桥 → 戏台 → 染坊 → 茶室 → 商铺招牌 → 阊门 → 山塘水陆 → 虎丘。JSON 保留附件原 ID，同时独立记录 route_order。这样 Next 不会从城内跳回乡野。

## 尺度与限制

完整姑苏母图宽高比约34.96:1，现有清明探索裁段约10.35:1。同等画面高度下，完整姑苏的拖行距离约3.38倍；建议保留全程和现有13进度点，让用户可直接跳到故事。不要为了“相同体验”挤压画作或误裁掉虎丘。

每个 box 是可见场景边界，不等于最终点击区域；交互标记仍保持现有像素大小。小课堂和茶室以建筑/人物组作为可见锚点，不把几像素文字当点击目标。现有细节图缓冲可复用，但边缘（茶室靠底、塔顶靠上）需限制到原图边界。
